S3Browser - profile test thủ công cho các phương thức đăng nhập
================================================================

Chỉ dùng cho môi trường Docker local, KHÔNG dùng cho môi trường thật.
Dựng môi trường: xem README.txt (mục 2 MinIO + LDAP, mục 3 Floci, mục 7 MinIO TLS + Keycloak).
Tên field bên dưới theo nhãn tiếng Anh trong form "Connection Profile" của app.

Kiểm thêm với mỗi profile:
  - Chạy cả "Test connection" và "Connect".
  - Tắt "Save secrets" thì mở lại app phải hỏi lại secret.
  - Bật "Auto connect" thì profile tự kết nối khi mở app (profile sai credential phải báo lỗi).


1. MinIO (README mục 2)
-----------------------

Field chung: Provider = MinIO | Endpoint = http://localhost:10010 | Path style = bật

  #    Method      Field cần nhập                              Kết quả mong đợi
  ---  ----------  ------------------------------------------  ------------------------------------------
  P1   Access key  Access key = s3b-rw-key                     Liệt kê bucket, upload, xoá được
                   Secret key = S3bRwKey#2026
  P2   Access key  Access key = s3b-ro-key                     Xem được; upload/xoá báo Access Denied
                   Secret key = S3bRoKey#2026
  P3   Access key  Access key = s3b-rw-key                     Báo lỗi sai credential
                   Secret key = sai-mat-khau
  P4   Anonymous   Buckets = anon-public-read,                 anon-public-read: chỉ đọc
                             anon-public-rw, demo-photos       anon-public-rw: đọc, upload, xoá được
                                                               demo-photos: không truy cập được
  P5   Anonymous   Buckets = (để trống)                        Bị chặn, cần ít nhất 1 bucket (PFE009)
  P6   MinIO STS   Access key = admin                          Kết nối được, toàn quyền
                   Secret key = MinioRoot#2026
  P7   MinIO STS   như P6                                      Xem/tải được; upload báo Access Denied
                   Inline policy = JSON chỉ đọc (cuối mục 1)
  P8   MinIO STS   như P6                                      Sau 15 phút app tự xin lại credential,
                   Duration (seconds) = 900                    thao tác không bị gián đoạn
  P9   LDAP        LDAP username = ldap-rw                     Đọc và ghi được
                   LDAP password = LdapRw#2026
  P10  LDAP        LDAP username = ldap-ro                     Chỉ đọc; upload báo Access Denied
                   LDAP password = LdapRo#2026
  P11  LDAP        LDAP username = ldap-rw                     Báo lỗi đăng nhập LDAP (S3E038)
                   LDAP password = sai-mat-khau
  P12  LDAP        như P9                                      Như P8
                   Duration (seconds) = 900
  P13  LDAP        như P9                                      Báo lỗi (cổng Console trả về HTML)
                   Endpoint = http://localhost:10011

  JSON chỉ đọc cho P7:
    {"Version":"2012-10-17","Statement":[{"Effect":"Allow",
     "Action":["s3:GetObject","s3:ListBucket","s3:ListAllMyBuckets","s3:GetBucketLocation"],
     "Resource":["arn:aws:s3:::*"]}]}

  Lưu ý:
    - MinIO STS chỉ chạy với tài khoản root; muốn quyền hạn chế thì dùng Inline policy như P7.
    - Khi MinIO bật LDAP, user nội bộ MinIO đăng nhập được nhưng mọi thao tác đều Access Denied.


2. AWS giả lập bằng Floci (README mục 3)
----------------------------------------

Field chung: Provider = AWS | Endpoint = http://localhost:4566 | Region = ap-southeast-1 | Path style = bật
Access key/secret key do Floci sinh ngẫu nhiên: lấy trong ~/.aws/floci-credentials (đã copy theo README).

  #    Method           Field cần nhập                                  Kết quả mong đợi
  ---  ---------------  ----------------------------------------------  -------------------------------------
  F1   Access key       Access key, Secret key = của [floci-rw]         Liệt kê bucket, upload, xoá được
  F2   Access key       Access key, Secret key = của [floci-ro]         Xem được; upload/xoá báo Access Denied
  F3   Access key       Access key, Secret key = của [floci-assumer]    Báo Access Denied (không có quyền S3)
  F4   Access key       Access key = AKIAFAKEFAKE                       Báo key không tồn tại
                        Secret key = bất kỳ
  F5   AWS CLI profile  AWS CLI profile = floci-rw                      Như F1
                        AWS config file = ~/.aws/floci-config
                        AWS credentials file = ~/.aws/floci-credentials
  F6   AWS CLI profile  như F5, AWS CLI profile = floci-ro              Như F2
  F7   AWS CLI profile  như F5, AWS CLI profile = khong-ton-tai         Báo profile không tồn tại (S3E033)
  F8   Anonymous        Buckets = s3b-public-read                       Xem và tải file được
  P-DC Default chain    (không có field, mở app như dưới)               Như F1

  Default chain: mở app từ PowerShell ở gốc repo, đổi AWS_PROFILE = floci-ro để thấy upload bị từ chối:
    $env:AWS_CONFIG_FILE = "$HOME\.aws\floci-config"
    $env:AWS_SHARED_CREDENTIALS_FILE = "$HOME\.aws\floci-credentials"
    $env:AWS_PROFILE = "floci-rw"
    go tool wails3 task dev

  Giới hạn của Floci (không phải lỗi app):
    - S3 không kiểm tra secret key: đúng access key + sai secret vẫn qua.
    - Request ẩn danh luôn được chấp nhận, kể cả bucket private (s3b-private).
  Chưa test được trên Floci: Assume role và AWS SSO. App chưa áp Endpoint cho STS nên request
  đi tới AWS thật. Hai method này cần test trên AWS thật.


3. MinIO TLS, OIDC và Client certificate (README mục 7)
-------------------------------------------------------

Field chung: Provider = MinIO | Endpoint = https://localhost:10020 | Path style = bật
File nằm trong test-env/certs/ (sinh bởi gen-certs.sh). Đăng nhập Keycloak: oidc-user / OidcUser#2026.

  #    Method              Field cần nhập                                     Kết quả mong đợi
  ---  ------------------  -------------------------------------------------  -----------------------------------
  P14  OIDC                Issuer URL = http://localhost:8180/realms/s3browser Đăng nhập Keycloak, Connect liệt kê
                           Client ID = s3browser                              bucket s3b-tls
                           Callback port = 48765
                           CA certificate file = ca.pem
  P15  OIDC                như P14,                                           Báo lỗi S3E041
                           Issuer URL = http://localhost:8180/realms/sai
  P16  Client certificate  Client certificate file = client/client.crt        Connect thành công
                           Private key file = client/client.key
                           CA certificate file = ca.pem
  P17  Client certificate  như P16, Private key file = client/client-enc.key  Connect thành công
                           The private key has a password = tick
                           Private key password = ClientKey#2026
  P18  Client certificate  như P17, Private key password = sai-mat-khau       Báo lỗi S3E043
  P19  Client certificate  như P17, Private key password = (để trống)         Báo lỗi S3E048
  P20  Client certificate  như P17, Private key file = client/client-legacy.key  S3E043 kèm gợi ý openssl pkcs8 -topk8
  P21  Client certificate  như P16, CA certificate file = (để trống)          Lỗi TLS "unknown authority", không treo
  P22  Client certificate  như P16, Client certificate file = file không có   Báo lỗi S3E042 kèm đường dẫn
  P23  Client certificate  như P16, Endpoint = http://localhost:10020         Báo lỗi PFE009 (cần https)
  P24  Access key          Access key = admin                                 Kết nối được
                           Secret key = MinioRoot#2026
                           CA certificate file = ca.pem
  P25  Access key          như P24, CA certificate file = file không có       Báo lỗi S3E049 kèm đường dẫn
  P26  Access key          như P24, CA certificate file = client/client.key   Báo lỗi S3E049 kèm đường dẫn

  Test hết hạn OIDC: Keycloak Admin (http://localhost:8180, admin / KeycloakAdmin#2026) -> realm s3browser
  -> Realm settings -> Tokens -> Access Token Lifespan = 2-3 phút.

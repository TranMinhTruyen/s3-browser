## [0.1.0] - Не выпущено

### Добавлено

- Диалог «Настройки» (кнопка слева от «История скачиваний»): тема (светлая / тёмная / как в системе), шрифт (Nunito, System UI, Segoe UI, Arial, Roboto, Be Vietnam Pro, Verdana, Meiryo UI, Monospace, JetBrains Mono), язык и запуск при старте Windows (только в установленной версии для Windows).
- Настройки сохраняются в `settings.json` рядом с `data.db` и загружаются до появления интерфейса, поэтому язык теперь запоминается.
- Изменения сразу показываются в предпросмотре. **Применить** сохраняет их до закрытия приложения, **Сохранить** записывает их в файл, **Сбросить** возвращает в форме значения по умолчанию.
- Тёмная тема.
- В комплекте шрифты JetBrains Mono, Roboto и Be Vietnam Pro.
- Перетаскивание вкладок для изменения их порядка. При закрытии приложение запоминает количество, порядок и профили открытых вкладок.
- Несколько способов аутентификации для каждого профиля подключения, выбираются в диалоге подключения:
  - AWS S3: ключ доступа (с необязательным токеном сессии), профиль AWS CLI, принятие роли (с необязательной MFA), AWS SSO, цепочка по умолчанию и анонимный доступ к введённым вами бакетам.
  - MinIO: ключ доступа, MinIO STS, LDAP / Active Directory, OpenID Connect (вход через системный браузер, код авторизации с PKCE), клиентский сертификат TLS (mTLS) и анонимный доступ.
  - Необязательный файл CA для серверов MinIO, сертификат которых выпущен частным центром сертификации.
  - Временные учётные данные автоматически обновляются до истечения срока, а если срок истекает во время передачи, показывается предупреждение.
  - Секреты (включая пароли LDAP и парольные фразы ключей) хранятся в зашифрованном виде. Сеанс OIDC хранится только в памяти; приложение никогда не сохраняет токен.
- Создание бакета (AWS S3 с выбором региона, MinIO) с необязательной установкой режима доступа при создании.
- Права доступа к бакету: приватный (без политики бакета), публичный только для чтения или пользовательская политика в формате JSON; предупреждение, если «Блокировка публичного доступа» отклонит публичную политику.
- Боковая панель со сведениями о бакете.
- Удаление бакета после ввода его имени. Непустой бакет сначала очищается, включая все версии и маркеры удаления. Непустой бакет с Object Lock удалить нельзя.
- В строках бакетов показывается значок типа политики (Приватный / Публичный / Пользовательский); он загружается отложенно только для видимых строк.
- Недоступные бакеты и бакеты, доступные текущей учётной записи только для чтения, помечаются в списке.
- Диалог с результатом после удаления нескольких объектов со списком того, что удалить не удалось.
- Проверка и установка обновлений из GitHub Releases: настройка автоматической проверки и скачивания обновлений, индикатор хода скачивания, проверка SHA-256 скачанного файла и подтверждение перед закрытием приложения для запуска установщика. Переключатель бета-версий позволяет получать предварительные выпуски.
- Интерфейс на упрощённом китайском, традиционном китайском, русском и немецком языках в дополнение к английскому, вьетнамскому и японскому (всего 7 языков). Языки загружаются по требованию.

### Изменено

- Переключатель EN / VI / JA в заголовке перенесён в диалог «Настройки».
- Цвета используют переменные темы, поэтому все экраны корректно выглядят в светлой и тёмной темах. Состояние подключения профиля показывается светло-зелёным / светло-красным цветом.
- Кнопки диалогов: «Отмена» слева, кнопки действий справа (подтверждение, загрузка, история, настройки).
- Фон окна при запуске соответствует сохранённой теме.
- Более плавная прокрутка длинных списков объектов и списка профилей подключения.
- События хода загрузки и скачивания отправляются пакетами, поэтому интерфейс остаётся отзывчивым при больших передачах.
- Смена языка или шрифта больше не подвешивает интерфейс, а раскладка вкладок сохраняется только при изменении.
- Уведомления исчезают через 10 секунд.
- Перед выполнением миграции создаётся резервная копия файла базы данных.
- Внутренняя чистка бэкенда и фронтенда (общие вспомогательные функции, удаление неиспользуемого кода) и больше модульных тестов.

## [0.0.1-beta.1] - 2026-10-28

Первый бета-выпуск.

### Добавлено

- Профили подключения: создание, изменение, удаление, автоподключение, секреты хранятся в зашифрованном виде.
- Подключение к AWS S3 и MinIO (конечная точка, регион, Path style), несколько подключений одновременно во вкладках.
- Просмотр бакетов, папок и объектов с постраничными списками.
- Поиск бакетов и объектов с постраничными результатами.
- Боковая панель со сведениями об объекте.
- Загрузка файлов и папок через диалог выбора или перетаскиванием, с ограничениями загрузки и окном хода выполнения.
- Скачивание одного или нескольких объектов параллельными частями, с окном хода выполнения, отменой и сохраняемой историей скачиваний.
- Удаление объектов и папок с шагом подтверждения.
- Интерфейс на английском, вьетнамском и японском языках.
- Портативная сборка для Windows, хранящая данные рядом с exe и включающая собственный WebView2.
- Документация: описание архитектуры и руководство пользователя (PDF) на трёх языках.

### Изменено

- Более быстрый запуск: тяжёлые диалоги загружаются по требованию, поэтому код, загружаемый при запуске, стал примерно на 24% меньше.
- Списки загружают по 20 элементов на страницу вместо 10, что сокращает число обращений при просмотре больших бакетов.
- Выбор объектов больше не перерисовывает всю вкладку.
- Внутренняя чистка бэкенда и фронтенда (общие вспомогательные функции, удаление неиспользуемого кода и зависимостей) и больше модульных тестов.

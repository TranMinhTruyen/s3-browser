## [1.1.0-beta.19] - 2026-11-22

### Добавлено

- Режим SQL теперь работает с файлами **SQLite**: профили баз данных (SQLite и PostgreSQL) сохраняются в базе данных приложения и остаются после перезапуска; для SQLite выберите файл `.db` в диалоге выбора файла и при желании откройте его **только для чтения**. **Подключиться** открывает настоящий файл (если файла нет или это не база данных SQLite, показывается ошибка).
- **Ctrl+E** и кнопка «Выполнить SQL» теперь действительно выполняют SQL (выделенное или всё): несколько операторов, разделённых `;`, выполняются по очереди и останавливаются на первой ошибке, с автофиксацией. Кнопка **Отменить выполнение** останавливает выполняющийся оператор. Для каждого оператора создаётся своя вкладка **Результат 1, 2…**, а вкладка **Сообщения** показывает операторы, число затронутых строк, время и ошибки. Строки результата подгружаются постранично (по 10 000 строк) при прокрутке; один оператор выполняется не дольше 5 минут.
- У карточки подключённого профиля есть **дерево объектов** (SQLite: Таблицы, Представления, Индексы, Триггеры; PostgreSQL: база данных, схема, затем те же группы, по-прежнему с примерами данных). Щелчок выделяет; двойной щелчок по таблице открывает **вкладку структуры таблицы** с подвкладками Данные, Столбцы, Индексы, Ограничения, Внешние ключи и Исходный код (сетка данных подгружает строки при прокрутке). Пункт **Обновить** в контекстном меню профиля перезагружает дерево.
- Автодополнение во вкладках SQL профиля SQLite теперь предлагает имена таблиц и представлений из дерева.

### Изменено

- Установщик и портативная версия теперь включают собственную библиотеку базы данных `s3b_db.dll` рядом с приложением.
- Внутри библиотека движка баз данных также поддерживает MySQL, MariaDB, PostgreSQL, SQL Server, MongoDB и Redis (к интерфейсу пока не подключены).

### Известные проблемы

- Профили PostgreSQL можно создавать и сохранять, но «Подключиться», дерево объектов и данные пока остаются примерами.
- Новые переводы режима SQL (вьетнамский, японский, упрощённый и традиционный китайский, русский, немецкий) не проверены носителями языка.
- Только Windows.

## [1.1.0-beta.18] - 2026-11-16

### Добавлено

- Режим SQL (предварительный просмотр интерфейса): новый переключатель **S3 / SQL** в заголовке окна переключает всё приложение между обозревателем S3 и рабочей областью SQL с тем же расположением, списком профилей и вкладками. При переключении состояние обоих режимов сохраняется. Серверной части для баз данных пока нет, поэтому профили хранятся только в памяти (есть несколько примеров профилей), а «Подключить», «Импорт», «Экспорт» и «Выполнить» лишь показывают сообщение.
- Создание и редактирование профилей баз данных (PostgreSQL и SQLite) в диалоге, похожем на диалог подключения S3.
- Вкладки SQL с редактором кода: подсветка синтаксиса, номера строк, автодополнение ключевых слов SQL и примеров таблиц и столбцов (Ctrl+Space); у каждой вкладки свой профиль. Редактор следует светлой/тёмной теме и настройке шрифта.
- **Ctrl+Q** форматирует SQL (весь текст или только выделенное). **Ctrl+F** открывает поле поиска и замены с параметрами «Учитывать регистр», «Слово целиком» и «Использовать регулярное выражение», а также кнопками «Найти», «Заменить» и «Заменить все». **Ctrl+E** и кнопка «Выполнить SQL» показывают SQL, который будет выполнен (выделенное или всё).
- Размер интерфейса в настройках: выберите мелкий, средний или крупный с помощью ползунка; всё приложение, включая окна Downloader и Uploader, масштабируется сразу, а выбор сохраняется вместе с остальными настройками.

### Известные проблемы

- Переводы режима SQL (вьетнамский, японский, упрощённый и традиционный китайский, русский, немецкий) не проверены носителями языка.

## [1.0.1] - 2026-11-10

### Изменено

- Обновлены зависимости, включая AWS SDK for Go, пакеты Go `x`, Mantine 9.8 и i18next 27.1.

### Исправлено

- Размеры файлов теперь подписываются как КиБ / МиБ / ГиБ, что соответствует единицам по 1024, в которых они вычисляются. Ограничение размера при импорте файла профиля показывается как 1 МиБ.
- Публичная политика бакета «только чтение», в которой операторы идут в другом порядке, теперь отображается как «Публичный», а не «Пользовательский».
- Боковая панель со сведениями о бакете сразу показывает новые права после сохранения политики бакета.
- **Применить** в настройках теперь применяет и запуск при старте Windows. Отмена после **Применить** не откатывает это изменение.
- Пока выполняется **Применить**, настройки изменить нельзя, а диалог экспорта профиля нельзя закрыть во время экспорта файла.
- Переключение бета-канала во время проверки обновлений больше не показывает результат прежнего канала; проверка запускается заново для нового канала.
- Удаление бакета останавливается с ошибкой вместо бесконечного цикла, если сервер возвращает некорректный список версий, показывает понятное сообщение, если бакет всё ещё не пуст, и больше не считает удалённые объекты дважды.
- Диалог подключения теперь отклоняет те же URL издателя (issuer) OpenID Connect, что и серверная часть (например, `http://127.1`).

## [1.0.0] - 2026-11-09

### Добавлено

- Диалог «Настройки» (кнопка слева от «История скачиваний»): тема (светлая / тёмная / как в системе), шрифт (Nunito, System UI, Segoe UI, Arial, Roboto, Be Vietnam Pro, Verdana, Meiryo UI, Monospace, JetBrains Mono), язык и запуск при старте Windows (только в установленной версии для Windows).
- Настройки сохраняются в `settings.json` рядом с `data.db` и загружаются до появления интерфейса, поэтому язык теперь запоминается.
- Изменения сразу показываются в предпросмотре. **Применить** сохраняет их до закрытия приложения, **Сохранить** записывает их в файл, **Сбросить** возвращает в форме значения по умолчанию.
- Тёмная тема.
- В комплекте шрифты JetBrains Mono, Roboto и Be Vietnam Pro.
- Перетаскивание вкладок для изменения их порядка. При закрытии приложение запоминает количество, порядок и профили открытых вкладок.
- Несколько способов аутентификации для каждого профиля подключения, выбираются в диалоге подключения:
  - AWS S3: ключ доступа (с необязательным токеном сессии), профиль AWS CLI, принятие роли (с необязательной MFA), AWS SSO, цепочка по умолчанию и анонимный доступ к введённым вами бакетам.
  - MinIO: ключ доступа, MinIO STS, LDAP / Active Directory, OpenID Connect (вход через системный браузер, код авторизации с PKCE), клиентский сертификат TLS (mTLS) и анонимный доступ.
  - Необязательный файл CA для серверов MinIO, сертификат которых выпущен частным центром сертификации.
  - Временные учётные данные автоматически обновляются до истечения срока, а если срок истекает во время передачи, показывается предупреждение.
  - Секреты (включая пароли LDAP и парольные фразы ключей) хранятся в зашифрованном виде. Сеанс OIDC хранится только в памяти; приложение никогда не сохраняет токен.
- Экспорт профиля подключения в файл JSON (щёлкните профиль правой кнопкой мыши, **Экспорт**) и импорт кнопкой **Импортировать профиль подключения**. Секреты необязательны; если они включены, они шифруются паролем. При импорте к повторяющемуся имени добавляется номер, пути к файлам, которых нет на компьютере или которые являются сетевыми путями или путями устройств, очищаются, а профиль не подключается.
- Создание бакета (AWS S3 с выбором региона, MinIO) с необязательной установкой режима доступа при создании.
- Права доступа к бакету: приватный (без политики бакета), публичный только для чтения или пользовательская политика в формате JSON; предупреждение, если «Блокировка публичного доступа» отклонит публичную политику.
- Боковая панель со сведениями о бакете.
- Удаление бакета после ввода его имени. Непустой бакет сначала очищается, включая все версии и маркеры удаления. Непустой бакет с Object Lock удалить нельзя.
- В строках бакетов показывается значок типа политики (Приватный / Публичный / Пользовательский); он загружается отложенно только для видимых строк.
- Недоступные бакеты и бакеты, доступные текущей учётной записи только для чтения, помечаются в списке.
- Диалог с результатом после удаления нескольких объектов со списком того, что удалить не удалось.
- Проверка и установка обновлений из GitHub Releases: настройка автоматической проверки и скачивания обновлений, индикатор хода скачивания, проверка SHA-256 скачанного файла и подтверждение перед закрытием приложения для запуска установщика. Переключатель бета-версий позволяет получать предварительные выпуски.
- Переключатели автоматического обновления и бета-версий в настройках действуют сразу, без нажатия **Сохранить**. При закрытии настроек с несохранёнными изменениями приложение предлагает **Назад**, **Отменить изменения** или **Сохранить**.
- Интерфейс на упрощённом китайском, традиционном китайском, русском и немецком языках в дополнение к английскому, вьетнамскому и японскому (всего 7 языков). Языки загружаются по требованию.
- Документация на всех 7 языках: README, руководство пользователя (с PDF), описание архитектуры и этот журнал изменений.

### Изменено

- Переключатель EN / VI / JA в заголовке перенесён в диалог «Настройки».
- Цвета используют переменные темы, поэтому все экраны корректно выглядят в светлой и тёмной темах. Состояние подключения профиля показывается светло-зелёным / светло-красным цветом.
- Кнопки диалогов: «Отмена» слева, кнопки действий справа (подтверждение, загрузка, история, настройки).
- Фон окна при запуске соответствует сохранённой теме.
- Более плавная прокрутка длинных списков объектов и списка профилей подключения.
- События хода загрузки и скачивания отправляются пакетами, поэтому интерфейс остаётся отзывчивым при больших передачах.
- Смена языка или шрифта больше не подвешивает интерфейс, а раскладка вкладок сохраняется только при изменении.
- Уведомления исчезают через 10 секунд.
- Перед выполнением миграции создаётся резервная копия файла базы данных.
- Внутренняя чистка бэкенда и фронтенда (общие вспомогательные функции, удаление неиспользуемого кода) и больше модульных тестов.

### Удалено

- Сборки для macOS и Linux. Теперь S3Browser выпускается только для Windows 10/11 (x64).

### Известные проблемы

- Удаление файлов или папок в бакете с управлением версиями только добавляет маркеры удаления; старые версии остаются в бакете. При удалении самого бакета удаляются все версии.
- Публичная политика бакета «только чтение», в которой операторы идут в другом порядке (например, записанная другим инструментом), отображается как «Пользовательский».
- За одну загрузку автоматически отмечается не более 50 файлов на папку (4 больших файла, всего 1000 файлов); файлы, выбранные в диалоге выбора файлов, считаются одной папкой.
- Размеры файлов вычисляются в единицах по 1024, но подписываются как КБ / МБ / ГБ.

## [0.0.1-beta.1] - 2026-10-28

Первый бета-выпуск.

### Добавлено

- Профили подключения: создание, изменение, удаление, автоподключение, секреты хранятся в зашифрованном виде.
- Подключение к AWS S3 и MinIO (конечная точка, регион, Path style), несколько подключений одновременно во вкладках.
- Просмотр бакетов, папок и объектов с постраничными списками.
- Поиск бакетов и объектов с постраничными результатами.
- Боковая панель со сведениями об объекте.
- Загрузка файлов и папок через диалог выбора или перетаскиванием, с ограничениями загрузки и окном хода выполнения.
- Скачивание одного или нескольких объектов параллельными частями, с окном хода выполнения, отменой и сохраняемой историей скачиваний.
- Удаление объектов и папок с шагом подтверждения.
- Интерфейс на английском, вьетнамском и японском языках.
- Портативная сборка для Windows, хранящая данные рядом с exe и включающая собственный WebView2.
- Документация: описание архитектуры и руководство пользователя (PDF) на трёх языках.

### Изменено

- Более быстрый запуск: тяжёлые диалоги загружаются по требованию, поэтому код, загружаемый при запуске, стал примерно на 24% меньше.
- Списки загружают по 20 элементов на страницу вместо 10, что сокращает число обращений при просмотре больших бакетов.
- Выбор объектов больше не перерисовывает всю вкладку.
- Внутренняя чистка бэкенда и фронтенда (общие вспомогательные функции, удаление неиспользуемого кода и зависимостей) и больше модульных тестов.
